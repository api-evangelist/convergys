# Convergys

> Convergys Corporation was a global customer-management company — contact-center
> outsourcing, workforce management, customer analytics and digital customer
> experience — acquired by SYNNEX and merged into Concentrix in October 2018. The
> brand is retired. This is an API Evangelist profile of a company that no longer
> operates, kept so that the Convergys name resolves to an accurate record rather
> than to nothing.

## Status

- Convergys published no public API, developer program, or machine-readable contract
  that survives today. Probed 2026-09-07: no OpenAPI, Swagger, GraphQL, AsyncAPI,
  WSDL, gRPC, MCP server, or A2A agent card was found on any host this record knows.
- `www.convergys.com` is an Azure App Service redirect app that has been switched
  off. Every path — including `/`, `/.well-known/*`, and a control path that cannot
  exist — returns `HTTP/1.1 403 Site Disabled`, and the host's TLS certificate has
  expired, so HTTPS does not complete a handshake.
- `developer.convergys.com` still resolves (151.214.119.116, an address block
  registered to Concentrix CVG Brite Voice Systems LLC) but TCP 80 and 443 are both
  closed. A developer host existed once; it is decommissioned.
- The successor company, Concentrix, is profiled separately. Anything a reader wants
  from "the Convergys API" today belongs to that record, not this one.
